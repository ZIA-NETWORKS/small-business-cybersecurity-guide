# Small Business Cybersecurity Guide

Practical cybersecurity guidance for small businesses that rely on
cloud applications, email, connected devices, and remote work.

## Overview

Small businesses depend on technology for communication, customer
information, financial operations, cloud applications, and everyday
business activities.

A practical cybersecurity strategy can help organizations protect
important information, reduce avoidable risks, and maintain reliable
business operations.

This guide covers several foundational areas of small business
cybersecurity.

## What This Guide Covers

- Multi-factor authentication (MFA)
- Password and account security
- Microsoft 365 security
- Software and operating system updates
- Employee security awareness
- Network security
- Endpoint protection
- Data backups
- User access management
- Cloud security
- Incident response planning

## 1. Multi-Factor Authentication

Enable multi-factor authentication for important business accounts
whenever the service supports it.

Priority accounts can include:

- Business email
- Microsoft 365
- Cloud applications
- Financial accounts
- Administrator accounts
- Remote-access services

MFA provides an additional verification step beyond a password.

## 2. Keep Software Updated

Businesses should maintain a regular process for updating:

- Operating systems
- Business applications
- Web browsers
- Network equipment
- Security software
- Cloud-connected devices

Keeping software current can help address known security
vulnerabilities.

## 3. Secure Microsoft 365

Businesses using Microsoft 365 should regularly review:

- Administrator accounts
- Authentication settings
- User permissions
- External sharing
- Account activity
- Security configurations

Access should be limited to what users need to perform their jobs.

## 4. Maintain Reliable Backups

Important business information should be backed up using an appropriate
backup strategy.

Businesses should also periodically test restoration procedures.
A backup strategy is most useful when important data can actually be
restored when needed.

## 5. Train Employees

Employees are an important part of an organization's cybersecurity
strategy.

Security awareness training should cover common risks such as:

- Phishing emails
- Suspicious links
- Unexpected attachments
- Social engineering
- Credential theft
- Fraudulent payment requests

Employees should also know how to report suspicious activity.

## 6. Manage User Access

Businesses should regularly review who has access to systems and
sensitive information.

When employees change roles or leave an organization, their access
should be reviewed and updated.

Administrator privileges should be limited to accounts that genuinely
require them.

## 7. Protect Networks and Devices

Businesses should maintain appropriate security controls for their
networks, computers, servers, and other connected devices.

Security practices can include network segmentation where appropriate,
endpoint protection, secure configurations, regular updates, and
monitoring.

## 8. Prepare for Security Incidents

Businesses should have a basic incident response plan.

The plan should identify:

- Who is responsible for responding
- Which accounts should be secured
- How affected devices should be isolated
- Where important backups are located
- Who should be contacted for technical assistance
- How business operations can be restored

Planning before an incident can make the response more organized.
